# Frontend (React 19, Vite, Tailwind, shadcn/ui)

Full detail: [`../../docs/ai/frontend.md`](../../docs/ai/frontend.md).

- Function components; `export default` for pages, named exports for components
  and libs. Import via the `@/` alias (`frontend/`).
- **No browser storage.** No `localStorage`, `sessionStorage`, cookies or
  IndexedDB — the app runs in a sandboxed frame where they throw, and a
  self-scored ledger must not be editable by the scoree. State lives in
  `lib/store.ts` (backend-backed) or component state.
- Style with the semantic tokens (`bg-card`, `text-accent`, `border-border`,
  `text-muted-foreground`) or the `.panel` class through `cn()` from
  `@/lib/utils`. No raw hex, no `slate-*`, no `bg-panel` (that class does not
  exist), no one-off panel where `components/kit.tsx` already has a primitive.
- Data: `@tanstack/react-query` with the shared client; live data through
  `openRoundSocket`. Do not add a second socket or a `setInterval` poll where the
  store already pushes.
- Charts go through `components/charts.tsx` (recharts). Forms use
  `react-hook-form` + `zod`; toasts use `sonner`; icons from `lucide-react`.
- `frontend/lib/source-archive.json` is generated by
  `scripts/package-source.sh` — never hand-edit.
- Mirrored maths lives in `lib/stats.ts`, `lib/pipeline.ts`,
  `lib/verifyForecast.ts`, `lib/backtest.ts`, `lib/ledger.ts`. Change the Python
  twin in the same commit and update `frontend/test/hiteta.test.ts`.
- Any model figure rendered must carry its measured quality (Brier skill, log
  loss, reliability, sample size). Copy says what the maths says.

Verify with `npx tsc -p tsconfig.app.json --noEmit` and `npx vitest run`.
